# Java Calculator

A simple calculator application developed using Java.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus

## Technologies Used

- Java
- Scanner
- Switch Statement

## How to Run

1. Download or clone this repository.
2. Open `Calculator.java` in a Java IDE.
3. Compile and run the program.
4. Enter two numbers and select an operator.

## Example

Enter first number: 20  
Enter operator: *  
Enter second number: 5  

Result = 100.0
